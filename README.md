#  Shubham Patel — macOS Inspired Portfolio

An interactive, responsive, and feature-rich **macOS-themed Developer Portfolio** built with **React**, **Tailwind CSS**, and **Vite**. 

This portfolio replicates a modern desktop operating system experience right inside the browser—complete with draggable app windows, dynamic photo gallery, custom skills terminal, interactive Finder project view, and creator studio integration.

---

## ✨ Features & Highlights

- ** Authentic macOS UI/UX:** Clean top bar, interactive dock app icons, fluid window controls (Close, Minimize, Expand), and smooth draggable window management.
- **📁 Finder Projects Explorer:** Interactive file system showcasing full-stack projects including *AI Voice Recruiter*, *PDF to MCQ Generator*, *Taskflow App*, and *ANiiMER Studio*.
- **📸 Dynamic Photos Gallery:** Replicated macOS Photos app featuring:
  - **Library:** Infinite scrolling grid view of travels & moments.
  - **Places:** Interactive location folders (*Kedarnath*, *Nainital*, *G.L. Bajaj / Noida*).
  - **Memories:** Automated smooth slideshow experience.
  - **People & Favorites:** Tag-filtered dynamic views.
- **🎬 Creator Integration:** Dedicated desktop shortcuts and dashboard integrations for **ANiiMER Studio** (2D Anime Content Creation across Instagram & YouTube).
- **💼 Work & Education:** Detailed experiences including *FinxThon '24 Hackathon (6th Rank)*, *Open Source Contributions (markdown-reader, preCICE)*, and *100xDevs Cohort 3.0*.
- **🖥️ Responsive Screen Guard:** Custom desktop-optimized viewport blocker tailored for laptop & desktop viewing experiences.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Framework:** React.js (Vite)
- **Styling & UI Components:** Tailwind CSS, Lucide Icons, Custom CSS Utilities
- **State Management:** Zustand (Window Z-Index & Focus management)
- **Language:** JavaScript (ES6+), HTML5, CSS3
